# フリーレンテーマの画像

ここに置いた画像は `Themes/grimoire/` としてアプリに同梱され、設定 > テーマ で「フリーレン」を選ぶと使われる。
無いものは色だけで描かれる（設定 > テーマ に読み込めたものが一覧で出る）。PNG か JPG。
画風は白を基調にした高精細（霞んだ白・薄い藤色のグレー・緑の差し色）。

| ファイル名 | 用途 | 形 |
| --- | --- | --- |
| bg_home | ホームの背景 | 縦 9:16。上 1/4 に絵、下は白く淡く |
| bg_log | ログの背景 | 縦 9:16。白く淡く |
| bg_guide | 図鑑の背景 | 縦 9:16。白く淡く |
| bg_spots | 釣り場一覧シートの背景 | 縦 9:16 |
| bg_sheet | 設定・各シートの背景 | 縦 9:16 |
| tabbar | タブバーの帯 | 横 3:1 |
| tab_home / tab_log / tab_camera / tab_guide / tab_spots | タブのアイコン | 正方形。背景は純マゼンタ #FF00FF |
| ring_home | ホームの釣れ率の飾り枠 | 正方形。背景は純マゼンタ。中央は空ける |
| char_home | ホーム：釣れ率の円を両手で囲むキャラクター | 横 16:9。背景は純マゼンタ。円の位置と大きさは `char_home.json`（`{"cx":0.5,"cy":0.6,"d":0.45}`、画像の幅・高さに対する割合）に書く。無ければ中心・高さの 44% |
| char_log | ログ：右上のキャラクター | 縦 3:4。背景は純マゼンタ |
| char_guide | 図鑑：右上のキャラクター | 縦 3:4。背景は純マゼンタ |

背景が純マゼンタなら透明に抜く。純黒なら明るさを不透明度にして重ねる（黒が透ける）。
キャラクターの大きさと位置は 設定 > テーマ で微調整できる。
