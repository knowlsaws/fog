# 魔導書テーマの画像

ここに置いた画像は `Themes/grimoire/` としてアプリに同梱され、設定 > テーマ で「魔導書」を選ぶと使われる。
無いものは色だけで描かれる（設定 > テーマ に読み込めたものが一覧で出る）。PNG か JPG。

| ファイル名 | 用途 | 形 |
| --- | --- | --- |
| bg_home | ホームの背景 | 縦 9:16（上 1/4 に絵、下は暗く） |
| bg_log | ログの背景 | 縦 9:16 |
| bg_guide | 図鑑の背景 | 縦 9:16 |
| bg_spots | 釣り場一覧シートの背景 | 縦 9:16 |
| bg_sheet | 設定・各シートの背景 | 縦 9:16 |
| tabbar | タブバーの帯 | 横 3:1 |
| tab_home / tab_log / tab_camera / tab_guide / tab_spots | タブのアイコン | 正方形・純黒の背景（黒を透かして重ねる） |
| ring_home | ホームの釣れ率の飾り枠 | 正方形・純黒の背景・中央は空ける |
