# 転スラテーマの画像

`Themes/tensura/` としてアプリに同梱され、設定 > テーマ で「転スラ」を選ぶと使われる。漆黒を基調に、テーマ色はリムルの水色。
ファイル名と形はフリーレンテーマ（`../grimoire/README.md`）と同じ。追加で `char_spots`（地図の左上、縦 3:4、マゼンタ背景）がある。

| 画面 | キャラクター | 備考 |
| --- | --- | --- |
| ホーム | ディアブロ（原初の黒） | 釣れ率の円を抱える。飾り枠は智慧之王（ラファエル）の魔法陣 |
| ログ | ウルティマ（原初の紫） | 右上 |
| 図鑑 | テスタロッサ（原初の白） | 右上 |
| 釣り場 | カレラ（原初の黄） | 地図の左上 |
| 撮影ボタン | スライム姿のリムル | タブバー中央 |
| 釣行詳細・各シート | 背景 `bg_detail`（水色の亀裂と、岩に座る人型のリムルとスライム） | テーマが無かった画面すべて |

背景：ホーム＝夜の魔国連邦テンペスト、ログ＝執務室の本棚、図鑑＝封印の洞窟の水晶、設定＝スライムのシルエット、釣り場一覧＝ジュラの大森林の古地図。
