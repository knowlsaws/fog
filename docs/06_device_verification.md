# 実機検証チェックリスト（L16・開発者）

L1〜L15 はすべて CI 緑でマージ済み。ここに書いたことは **iPhone 16 Pro（TestFlight）でしか確かめられない**ので、開発者が確認する。
確認できたら `docs/03_loop_plan.md` の状態を `done` にする。問題は `feedback` ラベルの Issue にする（1 件 1 Issue、画面のスクリーンショットを付ける）。

## 0. 準備（最初の 1 回）

- [ ] TestFlight から最新ビルドを入れる（main への push ごとに `testflight` ワークフローが配信する）
- [ ] 初回起動で位置情報「常に許可」、カメラ、写真、通知、モーションを許可する
- [ ] 設定 > カメラ > カメラコントロール で「Fog」を選ぶ（側面ボタンでアプリの撮影が開く）
- [ ] ホーム画面にウィジェット「釣れ率」の小と中、ロック画面に「釣れ率（ロック画面）」を置く
- [ ] iCloud にサインインしていること（設定 > データ に「iCloud に同期中」と出る）

## 1. 起動とホーム（L1, L2, L3, L9）

- [ ] 起動 → ホームが 1 画面に収まる（縦スクロールなし）。釣れ率の数字と円弧、4 チップ、イベント 3 件、先の推移と潮位曲線
- [ ] 釣り場名をタップで登録釣り場の切替。歯車で設定が開く
- [ ] 潮位曲線の満干時刻が気象庁潮位表（函館）と数分以内で一致する（L16 受け入れ条件）
- [ ] 機内モードで起動しても釣れ率・潮・マズメが出る（予報チップだけ「—」になる）
- [ ] 1 分ほど置いて風・天気のチップに値が入る（WeatherKit／Open-Meteo の実通信）

## 2. 撮影（L5, L6, L10）

- [ ] 撮影タブ → 1 秒以内にプレビューが出る（L10 受け入れ条件）
- [ ] 魚（または魚の写真）を 0.3〜0.9 m で写すと計測枠が緑になり、サイズが出る
- [ ] シャッター → 結果シート（魚種候補 3 種・サイズ・釣れ率）が 1.5 秒で閉じる。候補タップで確定
- [ ] 同じ魚を続けて撮っても 1 尾にまとまる（3 分以内・同魚種・近いサイズ）
- [ ] シャッター長押しで針ロスト／針追加
- [ ] カメラコントロールのボタンでアプリの撮影画面が開く
- [ ] 判定モデル未同梱のため魚種は「候補なし」になる → 写真を集めて `scripts/train_classifier/README.md` の手順で学習すると候補が出る

## 3. 釣行の自動検出（L4）

- [ ] 釣り場に着いて 10 分（感度「中」）で「記録を始めました」通知。ホームの釣り場名の左でオレンジの点が脈動
- [ ] 通知の「停止」で止まる。誤検出なら「誤検出なので破棄」で釣行が消える
- [ ] 300 m 離れて 30 分、または車で 5 分走ると終了通知（レポート要約と尾数）
- [ ] 釣行中に標準カメラで撮った写真が終了時に釣果として取り込まれる
- [ ] 丸一日の釣行（10 時間）でバッテリー消費 20% 以下（設定 > バッテリー で確認。L16 受け入れ条件）
- [ ] 圏外でも撮影・記録・釣れ率が動く
- [ ] 自動開始・終了のしきい値（`DetectionSettings.forSensitivity`）が実釣に合わなければ、感度を変えて試し、結果を `docs/04_decisions.md` に書く

## 4. ログ・図鑑・釣り場（L8, L11, L12, L13）

- [ ] ログ：期間セグメント、釣行カード（ボウズはグレー）、分析カード 3 枚、最新レポート 1 行が 1 画面に収まる
- [ ] 釣行カードをタップで詳細（時系列・軌跡・レポート）。長押しで削除 → 分析が即時に変わる
- [ ] 釣行終了後 10 秒以内にレポート（Foundation Models）が付く。Apple Intelligence が無効なら定型文になる
- [ ] 図鑑：釣った魚種だけが 3 列で並ぶ。直近 1 週間の記録更新にオレンジの点。魚種詳細が縦スクロールなしで収まる
- [ ] 図鑑の写真を長押しで魚種・サイズを修正 → 設定 > 判定 の修正履歴が増える
- [ ] 図鑑の修正シート「この釣果を削除」／釣行詳細の釣果行の長押しで削除。「写真ライブラリからも削除」で iOS の確認が出て写真も消える
- [ ] 釣り場：モノトーン地図、釣行数で大きさが変わる点、現在地の白、カード横スクロールで地図が追従、全国検索
- [ ] 釣り場詳細のヒートマップと根掛かりマップ

## 5. ウィジェット・通知（L14）

- [ ] 小ウィジェット：釣れ率と円弧、潮の矢印。タップでホーム
- [ ] 中ウィジェット：釣れ率、潮グラフ、次のイベント。撮影ボタンで撮影画面、タックル切替で表示が変わる、針ロストが次にアプリを開いたとき釣行に記録される
- [ ] ロック画面：釣れ率と次のイベントまでの時間。タップで撮影
- [ ] 釣行の記録中はウィジェット背景が薄いオレンジになる
- [ ] 15 分ごとに値が変わる（アプリを閉じたまま 1 時間置く）
- [ ] 通知 4 種：釣行開始（停止できる）、釣行終了、記録更新（アプリを閉じているときだけ）、釣れ率ピーク（登録釣り場で今日のピークが 80 以上のとき 1 時間前）
- [ ] 設定 > 通知 でオフにした種類が鳴らない

## 6. 設定・データ・iCloud（L15）

- [ ] タックルとリグ（最大 10）を登録。撮影画面のリグチップに出る
- [ ] CSV／JSON エクスポートの共有シートが開く。写真付き ZIP の進捗が出て共有できる
- [ ] JSON から復元で釣行数が戻る（同じ ID は重複しない）
- [ ] 全データ削除 → ログ・図鑑・釣り場が空になり、再起動後も空のまま
- [ ] iCloud 同期：同じ Apple ID の別端末（または再インストール後）に釣果が戻る（L15 受け入れ条件）
- [ ] 情報源に Open-Meteo（CC BY 4.0）と Apple Weather の帰属が出る

## 7. 既知の制約（Issue にしなくてよい）

- 魚種判定モデルは未同梱（学習用写真が必要）。候補は出ず、図鑑・分析は「魚種なし」として扱う
- RSS（F-27）、Apple Watch（F-25）、在庫管理（F-26）、手入力サイズ（F-12）は L17（COULD）で、開発者が指示したものだけ作る
- TestFlight の署名証明書は `scripts/ci/signing/` に暗号化保存。Apple の上限に当たったら `signing-admin` ワークフローで整理する
